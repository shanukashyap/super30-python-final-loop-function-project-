# Task 12 - Super30 Python Utility Application

A menu-driven application containing six utilities:
1. Calculator
2. Palindrome checker
3. Prime checker
4. Factorial calculator
5. Multiplication table
6. Number analyzer

## Concepts
Functions, `for` loops, `while` loops, conditions, lists, strings, and error handling.

## Run
```bash
python utility_application.py
```
