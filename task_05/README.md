# Task 05 - Number Analysis Tool

Analyzes a list for largest, smallest, total, average, even count, odd count, positive count, and negative count.

**Restriction:** `min()`, `max()`, and `sum()` are not used.

## Run
```bash
python number_analysis.py
```
Enter numbers: 10 20 5 -3 8

Largest: 20
Smallest: -3
Total: 40
Average: 8.0
Even Count: 4
Odd Count: 1
Positive Count: 4
Negative Count: 1
