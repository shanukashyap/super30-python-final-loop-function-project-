# Task 02 - Banking Application

A menu-driven banking program supporting balance checking, deposit, withdrawal, transaction history, and exit.

## Concepts
- Functions
- `while` loop for the menu
- Lists
- Input validation
- Error handling

## Run
```bash
python banking_application.py
```
