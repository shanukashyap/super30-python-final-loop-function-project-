# Task 01 - Student Result Management System

## Objective
Accept marks, calculate total and percentage, assign a grade, determine pass/fail, and display the result.

## Concepts
- Functions and docstrings
- `for` and `while` loops
- Dictionaries
- Input validation
- Conditional statements

## Sample
```text
Enter student name: Rahul
Enter marks for Python (0-100): 85
...
Total: 425.00
Percentage: 85.00%
Grade: A
Result: Pass
```

## Run
```bash
python student_result.py
```
